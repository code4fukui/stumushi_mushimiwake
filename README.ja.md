# 虫見分けゲーム スタ☆ムシ (stumushi_mushimiwake)

[東北プロコン2024](https://tohoku-procon.jp/contest/2024/award/nominate.html)に向けて作成された、ターミナル上で遊べる虫の見分けゲームです。

- **プロジェクトホームページ:** [スタ☆ムシ](https://www.yatex.org/gitbucket/touhoku_procon/touhoku_procon/pages/home.html)
- **元のダウンロードページ:** [虫見分けゲームダウンロードページ](https://www.yatex.org/gitbucket/touhoku_procon/touhoku_procon/pages/m_m_game_download.html)

## ゲームについて

このゲームでは、昆虫を**外来種**、**絶滅危惧種**、**固有種**のいずれかに分類します。ターミナルの上部に虫の画像が表示されるので、矢印キーを使って下部にある正しいカテゴリの箱に移動させてください。
